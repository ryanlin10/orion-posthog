# Security and privacy reports

Report vulnerabilities using GitHub's private vulnerability reporting feature when enabled. Do not attach real captured input, credentials, or user recordings to public issues. For non-sensitive defects, a generated reproduction is preferred.

Orion captures behavioural data. Its default mask sends key press and release times only; the opt-in `code` mask sends physical key codes, which can reveal typed content. The README documents default exclusions and the masks. The human labelling page listens on 127.0.0.1 only and refuses other host names. AI labellers send the text people wrote, or a session's event timeline, to the model provider with the customer's own key. Site owners must configure collection and consent appropriately for their application. The library cannot inspect private contents of cross-origin frames or closed shadow roots.
