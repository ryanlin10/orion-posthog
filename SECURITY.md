# Security and privacy reports

Report vulnerabilities using GitHub's private vulnerability reporting feature when enabled. Do not attach real captured input, credentials, or user recordings to public issues. For non-sensitive defects, a generated reproduction is preferred.

This library captures behavioral data. Physical key codes can reveal typed content. The README documents default exclusions and timing-only/off modes. Site owners must configure collection and consent appropriately for their application. The library cannot inspect private contents of cross-origin frames or closed shadow roots.
